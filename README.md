# Deskpoint

Aplikasi berbasis web untuk membantu pengelolaan dan monitoring proyek.

## Deskripsi

Deskpoint merupakan aplikasi manajemen proyek berbasis web yang dikembangkan menggunakan framework CodeIgniter 4. Aplikasi ini bertujuan untuk mempermudah proses pengelolaan proyek, pemantauan pekerjaan, serta pengorganisasian aktivitas proyek.

## Teknologi yang Digunakan

- PHP
- CodeIgniter 4
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Fitur

- Pengelolaan data proyek
- Monitoring progres proyek
- Pengelolaan tugas
- Pengorganisasian aktivitas proyek

## Persyaratan Sistem

- PHP 8.2 atau lebih baru
- MySQL
- Composer
- Web server (Apache)

## Instalasi

1. Clone repository:

   ```bash
   git clone https://github.com/ardianaryanandaa-ship-it/Deskpoint.git
   ```

2. Masuk ke direktori project:

   ```bash
   cd Deskpoint
   ```

3. Install dependency:

   ```bash
   composer install
   ```

4. Salin file `env` menjadi `.env`.

5. Sesuaikan konfigurasi database pada file `.env`.

6. Jalankan aplikasi:

   ```bash
   php spark serve
   ```

7. Buka browser:

   ```text
   http://localhost:8080
   ```
